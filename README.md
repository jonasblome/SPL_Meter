# SPL_Meter
An SPL Meter in Python, running on Raspberry Pi Zero W

# Quick-Start Guide
1. Install requirements: pip install -r requirements.txt
2. Run application: python src/main.py
3. View UI: go to http://127.0.0.1:8501 in your browser
